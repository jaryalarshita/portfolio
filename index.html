Synq

Serverless synthetic data engine & API mocker

Generates relational data from your own schemas. A topological sort of foreign-key dependencies keeps referential integrity (and names any cycles). It also includes a browser-only mock REST API with a chaos layer that injects latency and 500/429/404 errors, plus a live observability dashboard drawn in hand-written SVG.

Tend

AI back office for small PayPal sellers. You approve, Tend acts.

Tend pulls overdue invoices, refund requests, disputes and low stock from PayPal into one AG Grid approval queue. Gemini proposes an action for each item, and the owner approves, edits, or types plain-English commands that turn into Grid API calls with undo. Only approved rows run, and the server re-prices every plan from fresh PayPal data first.

  • React
  • Node.js
  • Express.js
  • Gemini API
  • PayPal APIs
  • AG Grid
  • 4 PayPal APIsinvoicing, payments, disputes, checkout
  • No double refundsidempotent request IDs per row
  • 3-model fallbackreuses cached reviews when Gemini is busy
